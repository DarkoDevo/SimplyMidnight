SimplyMidnight Overlay

Capture the WoW client, crop the in-game export strip, and mirror it into this external window for GGL.

1. Start the addon in WoW and unlock the HUD if you need to move it.

2. Click Start Capture and pick the WoW window or monitor.

3. Adjust crop values until the mirrored export strip fills the preview.

4. Transparent click-through overlay mode is reserved for a later phase.
