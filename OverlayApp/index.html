SimplyMidnight Overlay

Capture the WoW client, crop the in-game export strip, and mirror it into this external window for GGL.

Preset controls the recommended crop size and preview scale.
Choose the WoW window or your main monitor before starting capture.

1. Start the addon in WoW and unlock the HUD if you need to move it.

1a. In WoW, use /sm export ggl_legacy_5slot or another named profile so the addon and overlay are aiming at the same contract.

2. Click Start Capture and pick the WoW window or monitor.

3. If monitor labels are confusing, use Identify Screens to flash each display with its bounds.

4. Adjust crop values until the mirrored export strip fills the preview.

5. Transparent click-through overlay mode is reserved for a later phase.
